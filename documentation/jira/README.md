# Vistula Salon Masażu – Repozytorium projektu

Repozytorium stanowi wspólną przestrzeń roboczą zespołu projektowego, służącą do przechowywania kodu źródłowego, dokumentacji technicznej oraz pozostałych materiałów powstałych w trakcie realizacji projektu.

Jest ono bazą roboczą zawierającą rezultaty kolejnych etapów prac, umożliwiającą ich wspólne rozwijanie, aktualizowanie i archiwizowanie. GitHub zapewnia również kontrolę wersji oraz historię wprowadzanych zmian.

## Organizacja i kontrola pracy

Do zarządzania przebiegiem prac projektowych, przydzielania zadań, określania odpowiedzialności oraz monitorowania postępów wykorzystywana jest platforma Jira.

**Przestrzeń projektowa Jira:**

[Salon Masażu – Jira](https://darek334.atlassian.net/jira/software/projects/SM/summary)

## Zasady współpracy

Repozytorium jest publicznie dostępne w zakresie odczytu. Prawo do wprowadzania zmian przysługuje członkom zespołu posiadającym uprawnienia współpracowników.

Prace programistyczne i aktualizacje dokumentacji realizowane są zgodnie z przyjętymi zasadami kontroli wersji i organizacji pracy zespołowej.
