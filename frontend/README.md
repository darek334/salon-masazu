# Frontend

Moduł **Frontend** odpowiada za warstwę prezentacji aplikacji internetowej Vistula Salon Masażu. Jego zadaniem jest zapewnienie użytkownikom intuicyjnego i przejrzystego interfejsu umożliwiającego korzystanie z funkcjonalności systemu.

Warstwa frontendowa została oparta na technologiach HTML, CSS i JavaScript. Komunikuje się z warstwą backendową za pośrednictwem protokołu HTTP/HTTPS, wykorzystując format JSON do wymiany danych.
