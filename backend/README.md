# Backend

Moduł **Backend** jest warstwą pośrednią pomiędzy frontend a bazą danych, oraz będzie pełnił funkcję tak zwanych frontendów.

Warstwa backendowa została oparta na języku PHP. Komunikuje się z frontendem za pośrednictwem protokołu HTTP/HTTPS, wykorzystując format JSON, natomiast z bazą danych MySQL współpracuje przy użyciu biblioteki PDO.
